## Validation

The approved ZIP matched SHA-256
`cd8370f9483945496409ae7c6e81cdb7a4793616f7b1022ab6a5fb1f911ba4b4`.
Each member path was checked before extraction. All five PNGs matched the
provided SHA-256 manifest and passed full pixel decoding and visual inspection.
The motifs are bamboo resilience, bodhi wisdom, lotus clarity and beauty, a
mechanical arm for Nova, and bamboo slips for Jiandu; none uses an eyeball motif.

Matching alt text and visible illustration captions are present in the existing
English and Chinese README variants. Product introductions remain ordinary text,
so the artwork is not the only readable explanation on a narrow display.
Asset previews were checked at desktop width and 375 px; final GitHub README
rendering is checked separately against each merged documentation commit.
